# Salman Mustapa - Professional Portfolio

[![GitHub Profile](https://img.shields.io/badge/GitHub-abangucup-emerald?style=flat&logo=github)](https://github.com/abangucup)
[![Website](https://img.shields.io/badge/Website-salmanmustapa.my.id-blue?style=flat)](https://salmanmustapa.my.id)

A modern, minimalist, and high-performance portfolio website built for **Networking & Web Development** professionals. This portfolio showcases projects, clinical experience, technical skills, and live GitHub activity with a focus on clean 2D aesthetics and smooth user experience.

## ✨ Features

-   **Dynamic Project Showcasing**: 3-column grid layout for projects with filtering and "Load More" pagination.
-   **Live GitHub Integration**: 
    -   Real-time repository fetching with star counts and language indicators.
    -   Granular Activity Timeline mirroring GitHub's profile summary (grouped by month).
-   **Smooth 2D Animations**: Hand-crafted 2D vector avatar with a "breathing" animation and interactive logo effects.
-   **Dark & Light Mode**: Seamless theme switching with persistent storage using `localStorage`.
-   **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
-   **Interactive UI**: Grouped activity counts, progress bars for commits, and intuitive navigation.
-   **SEO Optimized**: Proper meta tags, semantic HTML5, and high accessibility standards.

## 🛠️ Tech Stack

-   **Frontend**: HTML5, Vanilla CSS3, [Tailwind CSS](https://tailwindcss.com/) (via CDN/Classes)
-   **Logic**: JavaScript (ES6+), [jQuery](https://jquery.com/)
-   **Icons**: [Lucide Icons](https://lucide.dev/)
-   **APIs**: 
    -   GitHub REST API (Live Repos & Events)
    -   GitHub Contributions API (Historical Data)

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to view this project locally.

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/abangucup/portfolio.git
    ```
2.  **Open the project**:
    Navigate to the project directory and open `index.html` in your browser.
