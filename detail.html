Ringkasan Proyek

Proyek ini dikembangkan untuk mendigitalisasi proses inventarisasi di laboratorium Sistem Informasi. Fokus utama adalah pada kemudahan pelacakan aset fisik dan laporan kerusakan secara real-time.

Fitur Utama

  • Multi-level Auth Admin, Teknisi, & Mahasiswa
  • QR Code System Identifikasi alat lab instan
  • Analytic Dashboard Monitoring real-time
  • E-Reporting Notifikasi kerusakan otomatis

Tantangan & Solusi

Sinkronisasi data antar modul laporan adalah tantangan terbesar. Solusinya adalah dengan impelementasi caching strategis dan optimasi query database untuk mempercepat pembacaan data dashboard yang berat.

Alur Kerja (Work Process)

1

Analysis

Observasi kebutuhan inventarisasi lab secara langsung.

2

Prototyping

Perancangan UI/UX fokus pada dashboard teknisi.

3

Development

Implementasi Backend & Integration testing.

Lessons Learned

"Dari proyek ini, saya belajar betapa krusialnya **User Feedback Loop** di awal pengembangan. Tanpa input langsung dari teknisi lab, sistem ini mungkin terlalu kompleks. Menyederhanakan alur input QR code terbukti meningkatkan efisiensi pendataan hingga 40%."
